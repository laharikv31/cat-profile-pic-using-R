I created a pixel art image of a cat for my GitHub profile picture using R. I took this up as a fun self-learning project that helped me experiment and beyond making basic plots in ggplot.
The basic principles behind this task are discrete matrix manipulation and pixel-to-coordinate mapping. The mapping can be done manually using tools such as makebead.com. (Claude makes mapping a lot easier too!)
Here, each pixel is drawn as a tile using geom_tile().
